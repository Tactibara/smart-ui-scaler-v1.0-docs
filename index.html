Introduction

Smart UI Scaler makes one Unity UI (uGUI) layout fit every screen. Design your UI once at a reference resolution, and Smart UI Scaler fits it into any screen size, aspect ratio, safe area or camera viewport, growing it toward the edges exactly as far as you allow. No more choosing between a layout that is cut off on phones and one that floats in the middle of an ultra wide monitor.

Why not the Canvas Scaler?

Unity's Canvas Scaler scales the whole canvas by one rule. Everything stretches or shrinks together, wide screens get empty margins or cropped edges, the safe area is your problem, and a single canvas cannot serve a split screen. Smart UI Scaler works per Rect Transform instead: each scaler is a rectangle with its own reference resolution and its own rules, and you can have as many of them as your screen needs.

What you get

  • 📐 Design once, ship everywhere
    Build the UI at your reference resolution and keep it readable from a phone in portrait to a 32:9 monitor.

  • 🛡️ Safe area done for you
    The UI stays inside the notch and home indicator insets, follows rotation and can stay centered when the inset is only on one side, while bars and backgrounds still reach the real screen edges.

  • 📏 You decide how the UI expands
    Choose how far the layout grows from its designed size toward the full screen and where it sits on the screen, and keep parts of it, such as a lobby or a card grid, between two aspect ratios.

  • 🔀 A layout per screen shape
    When one layout cannot serve every screen, give phones in portrait, tablets and wide monitors each a layout of their own. The right one is picked by the shape of the screen, and you edit each layout in its real shape. Images and backgrounds keep their proportions on every screen, never stretched.

  • 🧊 3D objects in the UI
    Lit 3D backgrounds, titles, spinning items and characters keep their place and size on every screen, like any other UI element. A character or an item can also be shown through a camera of its own, and it stays framed while it animates or changes equipment.

  • 🎚️ A UI scale slider for your players
    Let players make the UI smaller or larger while it keeps covering the same area. Bind it to a settings slider and the whole HUD follows.

  • 🧩 Several scalers on one screen
    HUD, menus, popups and split screen viewports each scale on their own terms. Scalers can be nested and mixed with regular UI in the same canvas.

  • 💾 Shared settings that persist
    Group scalers through assets, change their options at runtime and keep them between sessions with the built-in PlayerPrefs persistence or your own save system.

  • 🛠️ See it before you press Play
    The layout looks the same in Edit Mode and in Play Mode. Preview any aspect ratio, simulate safe areas and switch between device presets from one editor window.

  • ⚡ Nothing to pay per frame
    Scalers resize only when the screen, the safe area or their options change. In a steady frame the plugin only checks that nothing changed, with no allocations.

  • 🔌 Extensible
    Write custom scalers for render textures, read scaler sizes in the same frame through an update event, and learn from seventeen demo scenes that cover every feature.

What is included

  • Smart UI Canvas Scaler, Smart UI Expander, Smart UI Size Limiter, Smart UI Aspect Fitter and Smart UI Aspect Switch components
  • Smart UI Mesh Fitter, Smart UI World Follower and Smart UI Framing Bounds components for 3D objects in the UI
  • UI Scaler Groups with runtime API and PlayerPrefs persistence
  • Smart UI Scaler editor window with safe area simulation and presets
  • Seventeen demo scenes, from a single scaler to 3D objects in the UI and custom scalers
  • Full source code, online manual and scripting API, offline PDFs

Requirements

  • ❗ Unity 2022.3.0 or newer, tested up to Unity 6000.6
  • ❗ Unity UI (uGUI) canvases, Screen Space Overlay and Screen Space Camera. UI Toolkit is not supported.
