    Introduction

    Smart UI Scaler is a powerful replacement for Unity's built-in Canvas Scaler component. It offers advanced, flexible scaling features that make it easy to design responsive UI layouts for any screen size or device.

    Features

    • 🖼️ Broad Canvas Support
      Fully compatible with both Overlay and Camera screen space canvases.

    • 🛡️ Safe Area Support
      Automatically positions UI elements within the screen’s safe area (ideal for notched or rounded screens).

    • 💾 Persistent Settings
      Built-in support for saving and loading UI scaler settings via PlayerPrefs, with a customizable interface for your own advanced save/load logic.

    • 🧩 Scaler Grouping System
      Group UI scalers for better organization and apply settings across multiple canvases effortlessly.

    • 🎚️ Player-Controlled UI Scaling
      Allow players to customize the scale of the UI to suit their preferences.

    • 📏 Flexible Expansion Control
      Easily manage how your UI expands from your reference resolution to the full screen (ideal for wide and ultra wide displays).

    • 🛠️ Editor Tools Included
      Test UI layouts directly in the Editor, with safe area simulation and real-time scaling previews.

    Requirements

    • ❗ Unity 2022.3.0 or newer
