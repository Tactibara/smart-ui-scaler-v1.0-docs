Introduction

Smart UI Scaler makes one Unity UI (uGUI) layout fit every screen. Design your UI once at a reference resolution, and Smart UI Scaler fits it into any screen size, aspect ratio, safe area or camera viewport, growing it towards the edges exactly as far as you allow. No more choosing between a layout that is cut off on phones and one that floats in the middle of an ultra wide monitor.

Why not the Canvas Scaler?

Unity's Canvas Scaler scales the whole canvas by one rule. Everything stretches or shrinks together, wide screens get empty margins or cropped edges, the safe area is your problem, and a single canvas cannot serve a split screen. Smart UI Scaler works per Rect Transform instead: each scaler is a rectangle with its own reference resolution and its own rules, and you can have as many of them as your screen needs.

What you get

  • 📐 Design once, ship everywhere
    Build the UI at your reference resolution and keep it readable from a phone in portrait to a 32:9 monitor.

  • 🛡️ Safe area done for you
    The UI stays inside the notch and home indicator insets, follows rotation, and the Smart UI Expander lets bars and backgrounds still reach the real screen edges.

  • 📏 You decide how the UI expands
    Expand Progress sets how far the layout grows from the reference resolution to the full screen, Alignment sets where it sits, and the Smart UI Size Limiter keeps a layout between two aspect ratios.

  • 🎚️ A UI scale slider for your players
    Content Scale shrinks the UI while it keeps covering the same area. Bind it to a settings slider and the whole HUD follows.

  • 🧩 Several scalers on one screen
    HUD, menus, popups and split screen viewports each scale on their own terms. Scalers can be nested and mixed with regular UI in the same canvas.

  • 💾 Shared settings that persist
    Group scalers through assets, change their options at runtime and keep them between sessions with the built-in PlayerPrefs persistence or your own save system.

  • 🛠️ See it before you press Play
    The layout looks the same in Edit Mode and in Play Mode. Preview any aspect ratio, simulate safe areas and switch between device presets from one editor window.

  • ⚡ Nothing to pay per frame
    Scalers resize only when the screen, the safe area or their options change. In a steady frame the plugin only checks that nothing changed, with no allocations.

  • 🔌 Extensible
    Write custom scalers for render textures, read scaler sizes in the same frame through an update event, and learn from twelve demo scenes that cover every feature.

What is included

  • Smart UI Scaler, Smart UI Expander and Smart UI Size Limiter components
  • UI Scaler Groups with runtime API and PlayerPrefs persistence
  • Smart UI Scaler editor window with safe area simulation and presets
  • Twelve demo scenes, from a single scaler to split screen and custom scalers
  • Full source code, online manual and scripting API, offline PDFs

Requirements

  • ❗ Unity 2022.3.0 or newer, tested up to Unity 6000.6
  • ❗ Unity UI (uGUI) canvases, Screen Space Overlay and Screen Space Camera. UI Toolkit is not supported.
