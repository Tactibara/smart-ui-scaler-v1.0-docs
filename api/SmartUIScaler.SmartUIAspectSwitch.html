Switches aspect variants by the aspect ratio of a UIScaler screen area. Listens to the UIScaler on the same object, or the first parent one, and on every resize activates the layout of the matching variant and deactivates the layouts of the other variants. Objects that are not listed as layouts are left untouched. When the active variant changes the deactivated and activated events of the variants are invoked, then the Active Variant Changed event with the name of the new variant, then the listeners added with AddActiveVariantChangedListener(Action<UIScalerAspectVariant>, bool), so any other way of switching can be wired in the inspector or from code. In the editor layouts are switched and the inspector events invoked only in Preview scaling mode, the active variant is resolved in every mode.

AddActiveVariantChangedListener(Action<UIScalerAspectVariant>, bool)

Adds a listener invoked with the new ActiveVariant when it changes, after the layouts were switched and the variant events were invoked, before the canvas layout is rebuilt. Read PreviousVariant in the listener to know which variant was active before. A listener that throws is logged and does not stop the other listeners.

public void AddActiveVariantChangedListener(Action<UIScalerAspectVariant> listener, bool invokeIfResolved = true)
