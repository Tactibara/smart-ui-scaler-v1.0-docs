Class SmartUIMeshFitter

Namespace
SmartUIScaler
Assembly

Sizes and places a 3D object, for example a mesh or a whole model, inside the parent RectTransform, so it scales with the UI like any UI element. The bounds of all enabled Renderers on this GameObject and its children are fitted into the parent rectangle after the UIScalers are updated each frame. When SmartUIFramingBounds are found on this GameObject or its children, their typed-in volume is fitted instead, so an animated model keeps the same size while it moves. The back of the bounds is placed on the parent rectangle and moved toward the camera by Depth Offset, measured in UI units, so the depth and the offset scale together with the width and the height. Position and scale of the Transform are set by this component. Rotate a child object instead of this one: rotating this one around X or Y can skew it, because UIScalers do not scale depth. 3D objects are drawn under Screen Space Camera and World Space canvases, not under Screen Space Overlay canvases.
