Named aspect ratio band of a SmartUIAspectSwitch. The variant with the largest MinAspectRatio that is not wider than the UIScaler screen area becomes active; a screen area thinner than every variant activates the thinnest one. The Layout object is the default way of switching, the events allow any other reaction to be wired in the inspector.
