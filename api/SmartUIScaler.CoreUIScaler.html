Methods

AddResizedListener(Action, bool)

Adds a listener invoked after the UIScaler RectTransform was updated by a resize, before the child UIScaler behaviours are resized and before the canvas layout is rebuilt, so objects activated by the listener are fitted in the same frame. The SmartUIAspectSwitch components of this UIScaler have already switched their layouts when it is invoked. A listener that throws is logged and does not stop the other listeners.

public void AddResizedListener(Action listener, bool invokeIfResized = true)

Parameters

listener Action

Listener to add.

invokeIfResized bool

Invoke the listener immediately when the UIScaler was resized at least once, so a listener added after the first resize does not wait for the next one.
