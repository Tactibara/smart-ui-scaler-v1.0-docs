    Smart Ui Scaler editor window

    Smart Ui Scaler window helps to test and debug UI layouts. It can be found under "Tools" > "Smart Ui Scaler";

    Presets field

    This field is used to apply presets scriptable object values to Smart Ui Scaler window.

    To create a new presets scriptable object Right Click on Project Window then navigate to "SmartUiScaler" > "Editor" > "UiScalerEditorPresets".



    Warning

    UiScalerEditorPresets scriptable object should be placed inside "Editor" folder as this scriptable object only works in Editor.

    Presets scriptable object has the same options as Smart Ui Scaler window.



    Presets options will be applied when Presets scriptable object is selected. They can be reapplied by pressing the "Reapply Presets" button.

    Scaling Mode field

    Scaling Mode field controls how UiScalers are scaled in Edit Mode.

    Scaling Mode Description
    Fitted Reference Resolution Sets the size of UiScalers to reference resolution and scales them to fit inside their Canvased. This mode is recommended for UI development and is most convenient to work with.
    Reference Resolution Sets the size of UiScalers to reference resolution and keeps the scale to represent their reference resolution 1:1 in Unity units. This mode is also intended for UI development.
    Preview Enables full UiScalers resizing that represents how UiScalers will look like in Play Mode. It is not recommended edit UI layout when this mode is enabled.
    Note

    This field only works in Edit Mode and is ignored in Play Mode.

    Simulate Safe Area and Area fields

    These fields control the simulated screen safe area. To activate the safe area simulation enable the Simulate Safe Area toggle. The Area fields control unsafe areas from every screen border in pixels.

    Note

    Safe area simulation fields also work in Play Mode.
