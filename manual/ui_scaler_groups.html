UI Scaler groups

UI Scaler Groups are used to share and control UI Scaler options between UI Scalers. UI Scaler Groups are controlled through their scriptable objects. To create a UI Scaler Group scriptable object Right Click on Project Window then navigate to "SmartUIScaler" > "UIScalerGroup".

The UI Scaler Group scriptable object has a "Default Options" foldout with the same fields as the Smart UI Canvas Scaler component. These are the options every UI Scaler in the group starts with. At runtime Content Scale and Expand Progress can be changed through the scripting API, and the changed values apply to all UI Scalers in the group. Reference Resolution, Use Safe Area, Safe Area Symmetry and Alignment are fixed for the group.

To assign a Smart UI Canvas Scaler to this group drag the UI Scaler Group scriptable object into its "Group" field. The "Options" field disappears, as the group options are used instead.

Use one group for UI Scalers that should look like one UI, even when they sit on different canvases: the canvases of a camera stack, a HUD split over several canvases, or popups on a canvas of their own. A change of Content Scale or Expand Progress then applies to all of them at once, and they are saved as one group.

Content Scale and Expand Progress are changed with the SetContentScale and SetExpandProgress methods of the UI Scaler Group scriptable object (UIScalerGroupSo API). Once the options are changed, all active UI Scalers update automatically. Check out the Demo 6 inside the plugin, where a complete UI Scaler Group example is showcased.

Save Id field

The "Save Id" field identifies the group in saved data. It is generated when the scriptable object is created, so renaming or moving the asset does not affect saved settings. The "New" button generates a fresh Save Id, which detaches the group from any settings saved under the old one.

The editor keeps Save Ids unique across the project and shows a warning when two groups share one, because only one of them would be saved.

Persistence

Initially UI Scaler Group options are not saved and loaded. To have persistent UI Scaler Group options the easiest way is to use UI Scaler Groups Persistence Manager component. Just add this component to an empty GameObject in the first scene in your project. It keeps its GameObject alive across scene loads, and a second Persistence Manager loaded later removes itself. It loads the options from PlayerPrefs when it awakes and saves them when the game is paused or closed. The "Save Key" field is the PlayerPrefs key used for this.

For more advanced scenarios a custom saving and loading can be implemented through UIScalerGroups class GetSaveData() and SetSaveData(UIScalerGroupsSaveData) static methods.

Warning

Settings saved by version 1.0 are not restored after upgrading to 1.1.0 or later. Version 1.0 identified groups differently, so each group starts from its "Default Options" once and is saved in the new format from then on.
