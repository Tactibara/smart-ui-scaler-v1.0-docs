Staying in sync with UI Scalers

UI Scalers are resized by SmartUIManager just before the canvases are rendered, after all Update() and LateUpdate() calls of the frame. Code that reads a UI Scaler's size or position in Update() therefore sees the values of the previous frame, which shows as a one frame lag whenever the screen, the safe area or the camera viewport changes.

To read UI Scaler sizes in the same frame they were updated, subscribe to AfterScalersUpdatedEvent. It is invoked every frame right after all UI Scalers have been updated, in Play Mode and in Edit Mode. The Smart UI Mesh Fitters and Smart UI World Followers have already placed their objects and cameras by then, so the event also sees their final positions.

using SmartUIScaler;
using UnityEngine;

public class ScalerFollower : MonoBehaviour
{
	[SerializeField]
	private RectTransform _scaler;

	private void OnEnable()
	{
		SmartUIManager.AfterScalersUpdatedEvent += OnAfterScalersUpdated;
	}

	private void OnDisable()
	{
		SmartUIManager.AfterScalersUpdatedEvent -= OnAfterScalersUpdated;
	}

	private void OnAfterScalersUpdated()
	{
		var size = _scaler.rect.size;
	}
}

Listening to one UI Scaler

To react to a single UI Scaler, add a listener with AddResizedListener(Action, bool). It is invoked only when that UI Scaler was resized, right after its Rect Transform was updated and before its child behaviours and the canvas layout are updated, so objects the listener activates are fitted in the same frame. A Smart UI Aspect Switch on the UI Scaler has already switched its layouts by then. By default a listener added after the first resize is invoked immediately. Remove it with RemoveResizedListener(Action).

ScreenArea is the screen area, in screen pixels, that the UI Scaler was fitted to by its last resize, after the safe area was applied. Use it, for example, to choose a layout by the aspect ratio of the area instead of the whole screen.

Note

SmartUIManager is created automatically when the game starts and must not be added to a GameObject or destroyed manually.
