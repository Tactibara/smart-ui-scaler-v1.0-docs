Scripting define

Smart UI Scaler adds the SMART_UI_SCALER scripting define symbol to the Player Settings of every platform when the editor loads it. Code that should work with and without the plugin can check it, for example a shared HUD script or a plugin of your own that supports Smart UI Scaler as an option:

#if SMART_UI_SCALER
using SmartUIScaler;
#endif
using UnityEngine;

public class HudLayout : MonoBehaviour
{
	private void OnEnable()
	{
#if SMART_UI_SCALER
		SmartUIManager.AfterScalersUpdatedEvent += OnScalersUpdated;
#endif
	}

	private void OnDisable()
	{
#if SMART_UI_SCALER
		SmartUIManager.AfterScalersUpdatedEvent -= OnScalersUpdated;
#endif
	}

	private void OnScalersUpdated()
	{
	}
}

The symbol is added once to each platform in Edit > Project Settings > Player > Other Settings > Scripting Define Symbols, next to the symbols that are already there. When it is already set, nothing is changed. Adding it makes Unity compile the scripts once more after the plugin is imported.

If your code is in an assembly with its own assembly definition, add a reference to the SmartUIScaler assembly definition, so the code inside #if SMART_UI_SCALER can use the plugin's types.

Note

Unity does not remove a scripting define symbol when the plugin that added it is deleted. After removing Smart UI Scaler from a project, also remove SMART_UI_SCALER from the Scripting Define Symbols of each platform, otherwise the code inside #if SMART_UI_SCALER is still compiled and cannot find the plugin.
