Release notes

1.2.0

New

  • Smart UI Aspect Switch component switches between layouts, such as wide, standard and tall, by the aspect ratio of the UI Scaler's screen area, with events per layout and a listener for code. Each layout can be edited in its own shape: the inspector sizes the UI Scaler as on a screen with the layout's aspect ratio. See Smart UI Aspect Switch component.
  • Smart UI Aspect Fitter component keeps images and backgrounds at their aspect ratio, anywhere between fitting inside the parent and covering it, with alignment, a focal point and the aspect ratio taken from the Image or RawImage. See Smart UI Aspect Fitter component.
  • Smart UI Size Limiter has an Alignment field that places the limited Rect Transform inside the parent, for example on the bottom right corner instead of the center. Existing Size Limiters stay centered.
  • The Smart UI Scaler window has a "Show Safe Area Border" toggle that outlines the safe area in the Game view and shades the margins outside it, with a "Shade Unsafe Area" toggle for the shade. See Smart UI Scaler editor window.
  • Smart UI World Follower component shows a world object, such as a 3D model, inside a Rect Transform of the UI through a camera of its own, also in camera stacks and partly off-screen. See Smart UI World Follower component.
  • Smart UI Mesh Fitter component sizes and places a 3D object inside a Rect Transform, so lit meshes, such as a menu background and an emblem that casts a shadow on it, scale with the UI. See Smart UI Mesh Fitter component.
  • Smart UI Framing Bounds component describes the volume of a 3D object, such as a character, an item or a title, as a cylinder, a box or a sphere that can be rotated. A Smart UI World Follower keeps that volume inside its Target, with Framing Padding, Fit Height Only and smooth transitions, and a Smart UI Mesh Fitter fits it instead of measuring the Renderers, so moving and animated models keep the same size. Equipment with framing bounds of its own widens the framing, and the camera can be driven by Cinemachine or any other rig. See Smart UI Framing Bounds component.
  • "Safe Area Symmetry" option for UI Scalers and UI Scaler groups mirrors the safe area inset of one side to the opposite side, so a UI Scaler stays centered and split screen UI Scalers keep the same scale. See Smart UI Canvas Scaler component.
  • CoreUIScaler.ScreenArea reports the screen area a UI Scaler was fitted to, and AddResizedListener / RemoveResizedListener notify code when a UI Scaler was resized, in the same frame. See Staying in sync with UI Scalers.
  • The SMART_UI_SCALER scripting define symbol is added to every platform when the plugin is imported, so code can check for the plugin with #if SMART_UI_SCALER. See Scripting define.
  • New demo scenes: Aspect Fitter, Aspect Switch, Mesh Fitter, World Follower and Character Framing. The Split Screen demo shows Safe Area Symmetry. The description panel of every demo can be hidden with Alt+Shift+I. See Demo scenes.

Changes

  • The Smart UI Scaler component is renamed to Smart UI Canvas Scaler (class SmartUICanvasScaler). Existing scenes and prefabs keep working without changes.
  • All components are public, so they can be added with AddComponent<T>() and found with GetComponent<T>(). Options without a public property are set in the Inspector.
  • The Smart UI Scaler window keeps its settings when scripts are recompiled, is split into sections and has tooltips on every field. The Area fields are disabled outside "Preview" and Play Mode, and while "Simulate Safe Area" is off. An Area field cannot go past the opposite edge of the Game view. Presets no longer have a Scaling Mode: applying one switches to "Preview". The "PreviewPresets" asset is renamed to "No Safe Area Presets". In Preview mode the Scene view shows a reminder with an "Exit Preview" button.

Fixes

  • A UI Scaler that was disabled while its group options changed now applies the new options when it is enabled again.
  • Adding or removing a listener of SmartUIManager.AfterScalersUpdatedEvent from inside a listener no longer causes an error.
  • An exception thrown by a group listener is logged and no longer stops the other listeners.
  • A Smart UI Expander, Size Limiter or nested UI Scaler whose component is disabled is no longer resized by the UI Scaler above it. It keeps its Rect Transform until it is enabled again.
Note

When upgrading from 1.1.0, delete the Assets/Plugins/SmartUIScaler folder before importing 1.2.0. Importing a package never deletes files, and files that were moved or renamed in 1.2.0, such as the renumbered demos and the Smart UI Canvas Scaler script, would otherwise stay in the project next to their new copies. Your scenes, prefabs and UI Scaler group assets outside that folder keep working: they find the new scripts after the import.

1.1.0

New

  • Unity 6 support, tested up to Unity 6000.6. The minimum version stays Unity 2022.3.0.
  • SmartUIManager.AfterScalersUpdatedEvent is invoked every frame after all UI Scalers are updated. Use it to read UI Scaler sizes in the same frame. See Staying in sync with UI Scalers.
  • UI Scaler Group scriptable objects have a "Save Id" field that identifies the group in saved data. It is generated automatically and kept unique by the editor.
  • UI Scaler Groups Persistence Manager also saves when the application is paused, so settings survive on mobile when the app is closed from the background.
  • Twelve demo scenes, from the basic concepts to split screen and custom scalers. See Demo scenes.

Changes

  • UI Scalers refit when the safe area changes without a resolution change, for example when a phone with a camera cutout is turned upside down.
  • Content Scale is limited to a minimum of 0.1 and Expand Progress to the range 0 to 1.
  • The Scripts/Internal folder of the plugin is now Scripts/Core. If an empty Scripts/Internal folder is left in the project after upgrading, delete it.
Warning

Settings saved by version 1.0 through the UI Scaler Groups Persistence Manager are not restored by 1.1.0. Each group starts from its "Default Options" once and is saved in the new format from then on.
