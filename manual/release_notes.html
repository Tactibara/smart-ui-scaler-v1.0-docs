Release notes

1.1.0

New

  • Unity 6 support, tested up to Unity 6000.6. The minimum version stays Unity 2022.3.0.
  • SmartUIManager.AfterScalersUpdatedEvent is invoked every frame after all UI Scalers are updated. Use it to read UI Scaler sizes in the same frame. See Staying in sync with UI Scalers.
  • UI Scaler Group scriptable objects have a "Save Id" field that identifies the group in saved data. It is generated automatically and kept unique by the editor.
  • UI Scaler Groups Persistence Manager also saves when the application is paused, so settings survive on mobile when the app is closed from the background.
  • Twelve demo scenes, from the basic concepts to split screen and custom scalers. See Demo scenes.

Changes

  • UI Scalers refit when the safe area changes without a resolution change, for example when a phone with a camera cutout is turned upside down.
  • Content Scale is limited to a minimum of 0.1 and Expand Progress to the range 0 to 1.
  • The Scripts/Internal folder of the plugin is now Scripts/Core. If an empty Scripts/Internal folder is left in the project after upgrading, delete it.
Warning

Settings saved by version 1.0 through the UI Scaler Groups Persistence Manager are not restored by 1.1.0. Each group starts from its "Default Options" once and is saved in the new format from then on.
