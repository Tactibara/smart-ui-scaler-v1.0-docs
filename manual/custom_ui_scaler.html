Custom UI Scaler

A custom UI Scaler is needed when the parent Canvas has "Camera Screen Space" Render Mode and the attached camera renders into a Render Texture. The Smart UI Scaler component cannot know where the rendered image ends up on the screen, so a custom UI Scaler provides that information.

Demo 11 contains a complete implementation, RenderTextureUIScaler, for a canvas rendered into a Render Texture and shown by a RawImage. Use it as the reference for the steps below.

Implementation

Extend CoreUIScaler and implement these two methods:

Provide the screen space Rect of the area where the Render Texture is shown.

protected abstract Rect GetScreenRect()

Convert a screen space Rect to a world space Rect inside the Render Texture's Canvas.

protected abstract Rect ScreenRectToWorldRect(Rect screenRect)

Mark the class with [ExecuteAlways] so that the custom UI Scaler also works in Edit Mode, like the built-in components do.

Detecting changes

A UI Scaler resizes only when its Rect Transform has changed, which is what happens when the Canvas resizes. When the provided screen Rect can change on its own, for example because the RawImage moves on the screen, the custom UI Scaler has to request a resize itself. Override OnPreWillRenderCanvases, compare the current screen Rect with the previous one and set transform.hasChanged = true before calling the base method:

protected override void OnPreWillRenderCanvases()
{
	var screenRect = GetScreenRect();

	if (screenRect != _lastScreenRect)
	{
		_lastScreenRect = screenRect;
		transform.hasChanged = true;
	}

	base.OnPreWillRenderCanvases();
}

Inspector

The Group and Options fields of a UI Scaler are drawn by a custom inspector. To show them on a custom UI Scaler, add a nested editor class that extends CoreUIScalerEditor and append the custom fields after the base inspector:

#if UNITY_EDITOR
[UnityEditor.CustomEditor(typeof(MyUIScaler))]
class Editor : CoreUIScalerEditor
{
	public override void OnInspectorGUI()
	{
		base.OnInspectorGUI();

		serializedObject.Update();
		UnityEditor.EditorGUILayout.PropertyField(serializedObject.FindProperty("_outputImage"));
		serializedObject.ApplyModifiedProperties();
	}
}
#endif

Safe area

The "Use Safe Area" option intersects the provided screen Rect with the screen's safe area, so it only makes sense when the screen Rect is in real screen coordinates. Demo 11 uses it this way: the inner UI Scaler only occupies the part of the image that is inside both the screen and the safe area. Turn the option off when the output is not shown directly on the screen.
