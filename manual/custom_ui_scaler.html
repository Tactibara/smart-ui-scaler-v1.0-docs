    Custom Ui Scaler

    Custom Ui Scaler needs to be created when parent canvas has Camera Screen Space Render Mode and attached camera renders to Render Texture, as Smart Ui Scaler cant receive the screen space area of the rendered image of the canvas.

    To create a Custom Ui Scaler extend the CoreUiScaler.

    These two methos must be implemented:

    Provide screen space Rect of the Render Texture output image.

    protected abstract Rect GetScreenRect()

    Convert screen space Rect to world space Rect.

    protected abstract Rect ScreenRectToWorldRect(Rect screenRect)
