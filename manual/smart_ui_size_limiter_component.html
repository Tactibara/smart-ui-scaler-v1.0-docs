Smart UI Size Limiter component

Keeps a layout, such as a lobby or a card grid, between a minimum and a maximum aspect ratio inside its parent, so it neither stretches on ultrawide screens nor gets squeezed on tall ones. The Rect Transform gets a fixed reference height and an aspect ratio limited to the assigned min and max values.

Field Description
Reference Height Height set on the Rect Transform and used to calculate the width for the current aspect ratio. Minimum is 1.
Min Aspect Ratio Minimum limit for aspect ratio. For unlimited min aspect ratio - set the value to 0.
Max Aspect Ratio Maximum limit for aspect ratio. For unlimited max aspect ratio - set the value to 0.
Alignment Where the limited Rect Transform sits inside the parent, from (0, 0) bottom left to (1, 1) top right. (0.5, 0.5) centers it, (1, 0) keeps it on the bottom right corner, values in between split the free space.

How it works

Smart UI Size Limiter component depends on parent Rect Transform. It uses the parent Rect Transform's size to calculate the aspect ratio of its own Rect Transform. If the parent's aspect ratio is between the min and max limits the full parent size is occupied, otherwise the size is limited to the nearest limit. The free space left in the parent is split by the Alignment field.

Note

Smart UI Size Limiter component can work without UI Scaler in parent hierarchy. To keep it inside the safe area, place it under a UI Scaler with Use Safe Area enabled.
