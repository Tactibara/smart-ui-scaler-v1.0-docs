Demo scenes

The plugin ships with demo scenes under Assets/Plugins/SmartUIScaler/Demos, ordered from the most basic concept to the advanced ones. Every scene has a description panel that explains what to look at. Hide or show it with Alt+Shift+I in the Editor, in Edit Mode and in Play Mode. The shortcut can be changed in "Edit" > "Shortcuts" under "Smart UI Scaler". In Play Mode the button on its top right corner does the same. The choice is remembered for all demo scenes.

Most demos are meant to be explored without entering Play Mode: open "Tools" > "Smart UI Scaler", set the Scaling Mode to "Preview" and change the Game view aspect ratio.

Demos 13 to 15 use materials of the Built-in Render Pipeline. In a URP or HDRP project convert them with the render pipeline's material converter, otherwise they are drawn in magenta.

Demo Scene What it shows
1 Single Scaler One Smart UI Canvas Scaler with Expand Progress 1 that always fills the safe area. Markers stay anchored to its corners and edges while the aspect ratio changes.
2 Reference Resolution and Safe Area The same HUD layout in a 1600 x 900 and in a 900 x 1600 Reference Resolution, both with Expand Progress 0, next to Use Safe Area on versus off. Enable "Simulate Safe Area" and "Show Safe Area Border" in the editor window to see the difference.
3 Alignment Nine Smart UI Canvas Scalers, one per Alignment value, each in its own Screen Space Camera canvas. In Play Mode every viewport animates between wide and tall.
4 Expand Progress Three centered Smart UI Canvas Scalers with Expand Progress 0, 0.5 and 1.
5 Content Scale Two Smart UI Canvas Scalers with Content Scale 1 and 0.5. The boxes shrink, the covered screen area stays the same.
6 UI Scaler Groups A HUD and a portrait, two Smart UI Canvas Scalers bound to the same group. In Play Mode press Escape to open a menu whose sliders change the group's Expand Progress and Content Scale. The settings persist through PlayerPrefs.
7 Smart UI Expander A header background that uses Smart UI Expander to reach the canvas borders beyond the safe area.
8 Smart UI Size Limiter A lobby layout kept between a min aspect ratio of 1.8 and a max aspect ratio of 2.5.
9 Nested Behaviours A Smart UI Expander and a Smart UI Size Limiter nested inside a Smart UI Canvas Scaler.
10 Aspect Fitter The same picture inside three frames through Smart UI Aspect Fitters: Envelope Progress 0 shows the whole picture, Envelope Progress 1 covers the frame, and Envelope Progress 1 with a focal point keeps the character in view. See Smart UI Aspect Fitter component.
11 Aspect Switch One Smart UI Canvas Scaler with a Smart UI Aspect Switch that activates a wide, a standard or a tall layout depending on the aspect ratio. See Smart UI Aspect Switch component.
12 Split Screen Two split screen cameras, each with its own Smart UI Canvas Scaler fitted to its camera viewport, so both halves keep their layout on every screen shape. A toggle switches between scalers with Safe Area Symmetry None and Horizontal: with a simulated left safe area, None shrinks only the left scaler, Horizontal makes the right one give up the same width, so both keep the same scale and stay centered.
13 Mesh Fitter A lit menu background built from 3D objects: a normal-mapped tiled wall that a Smart UI Mesh Fitter in Envelope mode scales to cover the screen, and an emblem lifted off it with Depth Offset so it casts a shadow. Press Play to move the light. See Smart UI Mesh Fitter component.
14 World Follower Three shop cards and a gold sphere, each showing a world object through a Smart UI World Follower: a centered cube, a capsule with a raised Focus Point, an object whose camera is moved by a script with Move Camera off, and the sphere on a point target. See Smart UI World Follower component.
15 Character Framing A dress-up screen: a character in a room stays inside the area between the menu panels through a Smart UI World Follower with Smart UI Framing Bounds. Equipping items and raising the arms widen the framing smoothly, and a swaying camera shows that the framing holds from every angle. Press Play. See Smart UI Framing Bounds component.
16 After Scalers Updated Event A Smart UI Canvas Scaler in an animated camera viewport, followed by two frames on another canvas: one positioned in SmartUIManager.AfterScalersUpdatedEvent stays in sync, one positioned in Update() trails a frame behind. See Staying in sync with UI Scalers.
17 Custom UI Scaler A canvas rendered into a Render Texture and shown by a RawImage, with a custom UI Scaler inside that only uses the part of the image inside the screen and the safe area. See Custom UI Scaler.
Note

The demos use TextMeshPro for their description panels. If the TextMeshPro essential resources are not in your project yet, Unity offers to import them when a demo scene is opened.
