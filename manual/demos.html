Demo scenes

The plugin ships with twelve demo scenes under Assets/Plugins/SmartUIScaler/Demos, ordered from the most basic concept to the advanced ones. Every scene has an instructions panel that explains what to look at.

Most demos are meant to be explored without entering Play Mode: open "Tools" > "Smart UI Scaler", set the Scaling Mode to "Preview" and change the Game view aspect ratio.

Demo Scene What it shows
1 Single Scaler One Smart UI Scaler with Expand Progress 1 that always fills the safe area. Markers stay anchored to its corners and edges while the aspect ratio changes.
2 Reference Resolution and Safe Area The same HUD layout in a 1600 x 900 and in a 900 x 1600 Reference Resolution, both with Expand Progress 0, next to Use Safe Area on versus off. Enable "Simulate Safe Area" in the editor window to see the difference.
3 Alignment Nine Smart UI Scalers, one per Alignment value, each in its own Screen Space Camera canvas. In Play Mode every viewport animates between wide and tall.
4 Expand Progress Three centered Smart UI Scalers with Expand Progress 0, 0.5 and 1.
5 Content Scale Two Smart UI Scalers with Content Scale 1 and 0.5. The boxes shrink, the covered screen area stays the same.
6 Smart UI Expander A header background that uses Smart UI Expander to reach the canvas borders beyond the safe area.
7 Smart UI Size Limiter A lobby layout kept between a min aspect ratio of 1.8 and a max aspect ratio of 2.5.
8 Nested Behaviours A Smart UI Expander and a Smart UI Size Limiter nested inside a Smart UI Scaler.
9 UI Scaler Groups A HUD and a portrait, two Smart UI Scalers bound to the same group. In Play Mode press Escape to open a menu whose sliders change the group's Expand Progress and Content Scale. The settings persist through PlayerPrefs.
10 Split Screen Two Screen Space Camera canvases, one per split screen camera, each with its own Smart UI Scaler fitted to its camera viewport.
11 Custom UI Scaler A canvas rendered into a Render Texture and shown by a RawImage, with a custom UI Scaler inside that only uses the part of the image inside the screen and the safe area. See Custom UI Scaler.
12 After Scalers Updated Event A Smart UI Scaler in an animated camera viewport, followed by two frames on another canvas: one positioned in SmartUIManager.AfterScalersUpdatedEvent stays in sync, one positioned in Update() trails a frame behind. See Staying in sync with UI Scalers.
Note

The demos use TextMeshPro for their instruction panels. If the TextMeshPro essential resources are not in your project yet, Unity offers to import them when a demo scene is opened.
