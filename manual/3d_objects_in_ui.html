3D objects in the UI

Smart UI Scaler has two components that bring 3D objects into a layout that follows every screen shape, and one component that describes the volume they fit. They look similar, but each one changes something different. This page helps you choose.

Which one do I need?

The Smart UI Mesh Fitter makes the 3D object part of the UI: it is placed and sized inside a Rect Transform like any other UI element and drawn by the camera of the canvas. The Smart UI World Follower turns a Rect Transform into a window into a 3D world: the object stays where it is in its scene, and its own camera shows it in the Rect Transform.

Many objects, such as an item in an inventory, work with both. These questions decide:

Question If yes
Is the canvas Screen Space Overlay? Smart UI World Follower. The Mesh Fitter cannot draw 3D objects on Screen Space Overlay canvases.
Should the object be lit by lights of its own or use camera effects of its own, separate from the UI? Or does it belong to a scene, such as a character standing in a room? Smart UI World Follower
Otherwise: the canvas is Screen Space Camera or World Space, and the object is lit together with the UI Smart UI Mesh Fitter. It needs no extra camera, so it also suits many objects at once.

Left, part of the UI: two Smart UI Mesh Fitters size the 3D objects like UI elements. The tiled wall is set to Envelope and covers the whole screen at the proportions of its texture, resizing with every screen shape, and the emblem is set to Fit in a slot that stays in the center of the UI Scaler. The canvas is Screen Space Camera, so both are lit together with the rest of the UI and the emblem casts its shadow on the wall. Right, a window into a 3D world: the character belongs to a room with lights of its own, so a Smart UI World Follower shows it through its own camera in the free space between the menu panels.

Then, if the object changes its size through animations, poses or equipment, add Smart UI Framing Bounds to describe the volume that must always fit. It is not a third choice: it adds to either component.

Comparison

Smart UI Mesh Fitter Smart UI World Follower
What it changes The object: its position and scale The camera's projection, and with Move Camera also its position
Where the object lives Under a Rect Transform inside the canvas Anywhere in the scene
Camera The camera of the canvas A camera of its own, or the scene camera
Size of the object in its scene Changes with the UI Stays the same, the view zooms instead
Lights Lit together with the rest of the UI Lit by its own scene or lights of its own
Screen Space Overlay canvas Not drawn Works
Extra rendering cost None One camera per follower, unless the scene camera is used
With Smart UI Framing Bounds The typed-in volume is fitted instead of the measured Renderer bounds, so an animated model keeps its size The view zooms so the typed-in volume fits the Target, including equipment with framing bounds of its own
Typical use Lit backgrounds, emblems, 3D icons, coins, chests, items in slots and item inspectors Character screens, a character in a room between menu panels, item inspectors with lights of their own

Examples

You want Use
A lit background that covers the screen at the proportions of its texture Mesh Fitter set to Envelope, on a quad with the aspect ratio of its texture
A 3D logo on that background that casts a shadow on it Mesh Fitter set to Fit, with a Depth Offset
Rotating 3D icons, such as a coin next to the coin counter or an item in each slot of a shop grid Mesh Fitter with Use Bounding Sphere in each slot, rotating a child object. On a Screen Space Overlay canvas: World Follower with a camera of its own per slot
An item inspector where the player rotates and zooms an item, as in an RPG inventory Mesh Fitter with Use Bounding Sphere, rotating a child object, zoomed by resizing its slot. On a Screen Space Overlay canvas or with lights of its own: World Follower with Framing Bounds set to Sphere, zoomed by changing the Radius
A 3D title, tilted or gently swaying Mesh Fitter set to Fit in the title slot, rotating a child object. For a swaying title, Framing Bounds set to Box around its movement; Use Bounding Sphere would shrink a wide title
A character in a room that stays between the menu panels and fully visible while it equips a long sword World Follower on the scene camera with Clip To Target and Move Camera off, plus Framing Bounds on the character and on the sword

Combining them

  • Mesh Fitter and World Follower are not used on the same object. A scene can use both: a lit background with a Mesh Fitter behind the menu, and a character in a 3D room through a World Follower.
  • Smart UI Aspect Fitter is the 2D counterpart: it keeps images and Rect Transforms at their aspect ratio. The Fit and Envelope modes of the Mesh Fitter do the same for 3D objects.
