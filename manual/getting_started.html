    Getting started

    This guide will help you to setup the initial Smart UI Scaler.

    1. Create a new GameObject inside your Canvas;

    2. Add the Smart UI Scaler component to this GameObject. The Rect Transform of this GameObject will be driven by Smart UI Scaler and will automatically resize;

    3. At first the Smart UI Scaler will work in "Fitted Reference Resolution" mode. You can see in Scene View that Canvas is represented with gray border and Smart UI Scaler has green border. This mode is recommended for editing UI layouts inside Smart UI Scaler and to place objects without overlapping;

    4. Lets add some UI objects into our Smart UI Scaler. As an example here is 4 added Raw Images anchored to the corners of the Smart UI Scaler;

    5. Now to test the Smart UI Scaler component with our UI layout we can open "Smart UI Scaler" editor window under "Tools" > "Smart UI Scaler";

    6. This tool helps to test scaling without entering into Play Mode. Here we can change the current scaling mode into "Preview". This mode works exactly as it would in Play Mode;

    7. We can now see that out Smart UI Scaler takes up full area of the Canvas. Now you can test all the Smart UI Scaler component options to see them in effect;

    Note

    In "Preview" mode Smart UI Scalers border changes into Red color. This indicates that it is not advised to change the inner UI layout in this mode.

    1. Change back the "Scaling Mode" in "Smart UI Scaler" editor window to "Fitted Reference Resolution". Smart UI Scaler component will resize to reference resolution and you can continue to work on your UI layout. At this point you can remove the Canvas Scaler component from the Canvas object as it is no longer needed.
    Note

    As an alternative, closing the "Smart UI Scaler" window will also rest the "Scaling Mode" to "Fitted Reference Resolution".

    These steps showcase the basics of creating and testing your UI layout with an initial setup.
