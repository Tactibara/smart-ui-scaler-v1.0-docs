Getting started

This guide walks you through setting up your first Smart UI Scaler.

  1. Create a new GameObject inside your Canvas;

  2. Add the Smart UI Scaler component to this GameObject. The Rect Transform of this GameObject will be driven by Smart UI Scaler and will automatically resize;

  3. At first the Smart UI Scaler will work in "Fitted Reference Resolution" mode. You can see in Scene View that the Canvas is drawn with a gray border and the Smart UI Scaler with a green border. This mode is recommended for editing UI layouts inside Smart UI Scaler and to place objects without overlapping;

  4. Let's add some UI objects to our Smart UI Scaler. As an example, here are four Raw Images anchored to the corners of the Smart UI Scaler;

  5. Now to test the Smart UI Scaler component with our UI layout open the "Smart UI Scaler" editor window under "Tools" > "Smart UI Scaler";

  6. This window helps to test scaling without entering Play Mode. Change the Scaling Mode to "Preview". This mode works exactly as it would in Play Mode;

  7. Our Smart UI Scaler now takes up the full area of the Canvas. Now you can test all the Smart UI Scaler component options to see them in effect;

Note

In "Preview" mode the Smart UI Scaler border turns red. This is a reminder not to edit the inner UI layout in this mode, because the layout is scaled and its size depends on the Game view.

  1. Change back the "Scaling Mode" in "Smart UI Scaler" editor window to "Fitted Reference Resolution". The Smart UI Scaler resizes back to the reference resolution and you can continue to work on your UI layout. At this point you can remove the Canvas Scaler component from the Canvas, it is no longer needed.
Note

As an alternative, closing the "Smart UI Scaler" window also resets the "Scaling Mode" to "Fitted Reference Resolution".

These steps cover the basics of creating and testing a UI layout. The demo scenes show every option in action.
