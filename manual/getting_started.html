Getting started

This guide walks you through setting up your first UI Scaler. In this manual a UI Scaler is a Rect Transform driven by a Smart UI Canvas Scaler component, or by a custom UI Scaler, and the components placed under it, such as the Smart UI Expander, are UI Scaler behaviours.

  1. Create a new GameObject inside your Canvas;

  2. Add the Smart UI Canvas Scaler component to this GameObject. The Rect Transform of this GameObject will be driven by the UI Scaler and will automatically resize;

  3. At first the UI Scaler will work in "Fitted Reference Resolution" mode. You can see in Scene View that the Canvas is drawn with a gray border and the UI Scaler with a green border. This mode is recommended for editing UI layouts inside the UI Scaler, because the layout keeps its designed size;

  4. Let's add some UI objects to our UI Scaler. As an example, here are four Raw Images anchored to the corners of the UI Scaler;

  5. Now to test the UI Scaler with our UI layout open the "Smart UI Scaler" editor window under "Tools" > "Smart UI Scaler";

  6. This window helps to test scaling without entering Play Mode. Change the Scaling Mode to "Preview". This mode works exactly as it would in Play Mode;

  7. Our UI Scaler now takes up the full area of the Canvas. Now you can test all the Smart UI Canvas Scaler component options to see them in effect;

Note

In "Preview" mode the UI Scaler border turns red and the Scene view shows a reminder. This is a reminder not to edit the inner UI layout in this mode, because the layout is scaled and its size depends on the Game view.

  1. Change back the "Scaling Mode" in "Smart UI Scaler" editor window to "Fitted Reference Resolution". The UI Scaler resizes back to the reference resolution and you can continue to work on your UI layout.
Note

The Smart UI Canvas Scaler replaces Unity's Canvas Scaler component for everything inside the UI Scaler. The Canvas Scaler can stay on the Canvas, it has no effect on the UI Scaler and its content, but it is no longer needed and can be removed.

Note

As an alternative, closing the "Smart UI Scaler" window also resets the "Scaling Mode" to "Fitted Reference Resolution" and turns the safe area simulation and the safe area border off.

These steps cover the basics of creating and testing a UI layout. The demo scenes show every option in action.
