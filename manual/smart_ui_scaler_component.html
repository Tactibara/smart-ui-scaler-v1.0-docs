Smart UI Canvas Scaler component

The main component of this plugin that replaces the built-in Canvas Scaler component. It is placed on a child of a Canvas.

Group field

Used to assign this UI Scaler into a shared group with shared options. For more information see UI Scaler groups.

Options fields

These options are used when this UI Scaler is not assigned into a group.

Field Description
Reference Resolution The resolution your UI layout is designed for. In Edit Mode the UI Scaler has exactly this size. Minimum is 100 on each axis.
Use Safe Area Fit into the screen's safe area instead of the whole screen area.
Safe Area Symmetry Shown when Use Safe Area is on. Mirrors the safe area inset of one side to the opposite side, so the UI Scaler stays centered: None uses the safe area as reported, Horizontal applies the larger of the left and right insets to both sides, Vertical the larger of the top and bottom insets, Both mirrors both axes. Split screen UI Scalers with Horizontal keep the same scale when only one side has an inset.
Alignment Where the UI Scaler sits inside the Canvas area when it does not fill it, that is when Expand Progress is below 1.
Content Scale Additional scale applied to the children. 1 is the designed size, lower values shrink the UI while it keeps covering the same area. Minimum is 0.1, recommended range is 0.1 to 1.
Expand Progress How far the UI Scaler grows from the reference resolution (0) toward the whole available area (1). Allowed range is 0 to 1.

Warning

This UI Scaler only works in Canvases with "Screen Space Overlay" Render Mode or "Screen Space Camera" Render Mode where attached camera is rendering directly to the screen. When the attached camera renders to a Render Texture this UI Scaler cannot know the screen space area of the rendered image and this information has to be additionally provided.
